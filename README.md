## About

I'm a freelance data scientist based in Islamabad, Pakistan. I build Python-based solutions that turn messy data and repetitive manual work into dependable, intelligent systems: from retrieval-augmented generation (RAG) pipelines and AI agents, to scraping workflows and interactive dashboards.

This portfolio presents my services, selected projects (including work in progress, labelled honestly as such), and a way to get in touch.

## Services

- **NLP & RAG Builder:** document Q&A, knowledge-base chatbots, and retrieval pipelines grounded in your own data
- **Agentic AI Developer:** AI agents that use tools, make decisions, and automate multi-step tasks
- **Web Scraping:** reliable, structured data collection from websites, delivered as CSV, JSON, or databases
- **Dashboard Developer:** interactive dashboards that turn raw data into clear business insights

## Features

- **Light/dark theme toggle** with the preference saved in `localStorage`
- **Brass cursor glow** that follows the pointer with lerp easing
- **Scroll-reveal animations** powered by `IntersectionObserver`
- **Ledger-inspired design motif** used across sections
- **Responsive layout** for desktop, tablet, and mobile
- **No frameworks or build step**: just HTML, CSS, and vanilla JavaScript

## Getting Started

No installation or build tools are needed.

```bash
# Clone the repository
git clone https://github.com/codewithbilalshaheen-arc/Portfolio.git

# Move into the project folder
cd Portfolio

# Open index.html in your browser, or serve it locally:
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The site is fully static and can be hosted on GitHub Pages, Netlify, or Vercel.

**GitHub Pages:** go to *Settings → Pages*, choose the `main` branch and the root folder, then save.

## Customization

- **Colors:** edit the CSS custom properties at the top of the stylesheet.
- **Content:** update the text and project entries directly in `index.html`.
- **Photo:** replace the image in `assets/images/` and keep the same filename (or update the `src`).
